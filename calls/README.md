# calls

One file per call or chat, named `YYYY-MM-DD-who.md` (for example `2026-10-20-aidvantage.md`).

Each one records: who was called, the date and time, the rep's name or ID, **the reference number**,
what was asked, what they said in their words as closely as possible, and what happens next.

**No account numbers, SSN or FSA ID** in these files. They sync.

Why bother: a rep's word is not a document, and reps are sometimes wrong. A dated note with a name
and a reference number is what gets a wrong answer fixed later.
