# records

The filed originals: servicer letters, NSLDS exports, forms, and the borrower defense evidence.

**Local only. Nothing in this folder is ever committed** (`decisions.md` D-001). The `.gitignore`
enforces it three ways: this folder, the file extensions, and filename keywords.

Organized by source:

```
records/
  aidvantage/
  studentaid-gov/
  university-of-phoenix/     the borrower defense evidence
  wgu/
```

**This folder does not sync, so it exists only on the machine where a file was dropped.** The
borrower defense evidence in particular is worth a backup somewhere that is not this repo.
