# inbox

Drop things here for Claude to sort. Anything goes: a servicer letter, a screenshot of
studentaid.gov, the NSLDS export, an old University of Phoenix email, or a note saying "Aidvantage
said X on the phone."

Claude reads them in place, pulls the facts into the tracked files, and files the original into
`records/` at clock out.

**Nothing in this folder syncs**, on purpose (`decisions.md` D-001).
